Step 1 & Step 4: GSD / Super Power Rules Generator

Định nghĩa chuẩn Input tối thiểu và tự động sinh file cấu hình .agent-rules.md độc lập cho dự án (không gây ảnh hưởng sang chat session khác).

1. Chuẩn Input Tối Thiểu (Minimum Input Schema)

  • raw_dev_task: Câu mô tả hành động kỹ thuật rõ ràng.
  • module: Phân hệ nghiệp vụ (AUTH, PAYMENT, SEARCH...).
  • dev_notes: Tối thiểu 15 ký tự ghi chú công nghệ, table DB, API.
  • suggested_type: Backend, Frontend, Database, QA, DevOps.

2. Quy Ước Naming & Estimation

  • Cú pháp: [{TYPE}][{MODULE}] Action
  • Thang điểm: Dãy Fibonacci (1, 2, 3, 5, 8, 13, 21).
  • Trùng lặp: Cảnh báo khi Cosine Similarity >= 85%.
